Section 02

Failures — 13 raw, reclassified to 5

The first parallel run's 13 failures collapse into four groups once each is re-run alone.

Fixed during this run
ExperienceModule.ts — carousel-tile click blocked by a permanent overlay (4 tests). All of the module's carousel-tile click helpers used a plain (non-forced) .click() on .swiper-slide img[alt]. A permanent decorative play-icon overlay centered on every slide intercepts pointer events there — unlike the location/promo modals the existing clickThroughOverlays retry wrapper is built to dismiss, this overlay never goes away, so retrying the same actionability-checked click didn't help. Force-clicked at all 4 call sites instead. Verified passing post-fix; npm run build and npm run rules:check (127 files) both clean.
