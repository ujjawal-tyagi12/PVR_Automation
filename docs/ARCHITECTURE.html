Architecture

Strict three-layer flow, enforced by npm run rules:check (scripts/rule-engine.js + rules/framework-rule-engine.json).

Tests (src/tests/*.spec.ts)
  → Modules (src/modules/*Module.ts)
    → Pages (src/pages/*Page.ts)

Pages

src/pages/*Page.ts — locators as arrow functions, simple actions, constructor(private page: Page) {}. No business logic.

Modules

src/modules/*Module.ts / *Modal.ts — orchestrate one or more Pages via their methods. Use Logger. Never call page.locator().

Tests

src/tests/*.spec.ts — call modules/fixtures only. Tag every test.describe with a priority (@P0/@P1/@P2) and suite (@Smoke/@Regression) tag. Wrap phases in test.step().

Supporting layers

FolderRole
src/api/Thin REST clients (Auth/Order/Product)
src/fixtures/Playwright test/expect extensions
src/utils/Logger, WaitHelper, DataGenerator, ApiHelper, CustomTTAReporter
src/config/Env-driven config (.env.local)
src/testdata/Static fixtures data + types
