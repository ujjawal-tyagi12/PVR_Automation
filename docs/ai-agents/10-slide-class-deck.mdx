title: 10-Slide Class Deck
description: Condensed slide-by-slide outline for teaching this workflow.
---

1. **Title** — AI-Assisted Playwright Testing: Planner, Generator, Healer.
2. **The problem** — hand-written E2E suites are slow to write and slower to keep passing; naive AI-generated tests hallucinate selectors and ignore architecture.
3. **The layering** — Tests → Modules → Pages, enforced, not just documented.
4. **The three agents** — Planner (scope), Generator (code), Healer (fix), each with a narrow job.
5. **MCP grounding** — Playwright MCP + Chrome MCP: every locator comes from a real accessibility snapshot.
6. **The rule engine** — `rules:check` as a mechanical gate, not a style guide nobody reads.
7. **Live demo** — requirements doc in, passing spec out, one deliberate break, one Healer fix.
8. **Skills catalogue** — `/setup-framework`, `/generate-test-cases`, `/create-md-ticket`, `/playwright-mcp`, `/e2e-review`.
9. **Hands-on** — pairs run the loop against a real flow in the target app.
10. **Gate + next steps** — `rules:check` + tests green = done; where to find `docs/ai-agents/` for reference afterward.
