## Workflow

1. Read architecture constraints from `.claude/skills/playwright-mcp/references/rules.md`.
2. Ask **Planner** for scenarios, tags, and impacted files (input: `requirements/{module}.md`).
3. Ask **Generator** to write code only in approved folders, preferring MCP-grounded locators.
4. Run `npm run rules:check` and the relevant tests.
5. If failing, ask **Healer** to patch minimal code using logs/traces **and** MCP/Chrome
   evidence.
6. Re-run the rule engine and tests.
7. On success, publish `playwright-report/index.html`.

## Prompt templates

### Planner

```text
You are the Planner for this Playwright framework.
Goal: <feature>
Return:
1) scenario matrix
2) data needed
3) tags
4) impacted files
Follow Pages -> Modules -> Tests architecture.
```

### Generator

```text
You are the Generator for this Playwright framework.
Implement only approved planner scenarios.
Allowed folders: src/pages, src/modules, src/utils, src/tests, src/testdata.
Rules:
- Page objects in src/pages/*Page.ts
- Module/modal code in src/modules/*Module.ts
- Utility code in src/utils
- No direct page.locator usage in modules
```

### Healer

```text
You are the Healer for this Playwright framework.
Input:
- failing test
- logs
- trace/screenshot path
- rule-engine output
- optional Playwright MCP / Claude-in-Chrome evidence (console, network, snapshot)
Task:
Apply minimal patch, keep architecture intact, and avoid unrelated refactors.
Ground locator fixes in MCP/Chrome observations — do not guess selectors.
```

## In this repo

`/playwright-mcp` (`.claude/skills/playwright-mcp/SKILL.md`) implements this loop end to end,
grounded in Playwright MCP (`.mcp.json`) and, optionally, Claude in Chrome (`claude --chrome`).
